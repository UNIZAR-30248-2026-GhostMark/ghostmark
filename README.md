# GhostMark

Aplicación móvil que hace de máster automático del Killer de misiones: reparte los objetivos, valida las eliminaciones con un código de vida y resuelve las disputas.

| Carpeta | Contenido |
|---|---|
| `backend/` | Servidor: Java 21, Spring Boot, PostgreSQL con PostGIS |
| `mobile/` | App: React Native, Expo, TypeScript |
| `docs/` | Pila del producto, sprints, gestión, diseño, pruebas de aceptación y manual de usuario |

Todo el trabajo entra en `main` mediante *pull request* desde una rama `feature/<n.º de issue>-<descripción>`, `fix/<n.º de issue>-<descripción>` o `docs/<tema>`, con la aprobación del responsable de lo que toca (`.github/CODEOWNERS`). Las convenciones completas están en [`docs/README.md`](docs/README.md).
