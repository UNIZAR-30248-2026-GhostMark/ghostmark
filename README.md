# GhostMark

Aplicación móvil que hace de máster automático del Killer de misiones: reparte los objetivos, valida las eliminaciones con un código de vida y resuelve las disputas.

| Carpeta | Contenido |
|---|---|
| `backend/` | Servidor: Java 21, Spring Boot, PostgreSQL con PostGIS |
| `mobile/` | App: React Native, Expo, TypeScript |
| `docs/` | Pila del producto, sprints, gestión, diseño y memoria |

Todo el trabajo entra en `main` mediante *pull request* desde una rama `feature/<n.º de issue>-<descripción>`, con la aprobación de otra persona del equipo.
